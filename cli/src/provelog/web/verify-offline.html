Independent verification

Verify a record

Drop a ProveLog bundle and the standalone verifier recomputes every hash, signature, chain link, Merkle root, and RFC 3161 timestamp signature from scratch, entirely in your browser. It trusts neither the agent that produced the record nor the sink that stored it. Sectigo and FreeTSA timestamp tokens are verified offline against pinned roots. This page is a convenience; the same check runs offline in provelog verify.

Drop bundle.json or evidence.zip here
or choose a file to verify - verification runs entirely in your browser, nothing is uploaded
Paste bundle JSON instead
Prefer your own machine? pip install provelog then provelog verify bundle.json. The verifier is open source and the evidence format is specified in docs/SPEC.md, so anyone can build an independent implementation. The pinned Sectigo/FreeTSA roots validate the timestamp signature and certificate chain offline; online revocation (OCSP/CRL) is not checked. Completeness, that nothing was withheld before being recorded, is never claimed by this tool.
